# Deployment

This guide covers deploying GBoard to various environments.

## Docker Deployment (Recommended)

The easiest way to deploy GBoard is using Docker Compose.

### Prerequisites

- Docker 20.10+
- Docker Compose 2.0+
- 2GB RAM minimum
- 10GB disk space

### Production Docker Compose

```yaml
# docker-compose.prod.yml
version: '3.8'

services:
  postgres:
    image: postgres:16-alpine
    environment:
      POSTGRES_DB: gboard
      POSTGRES_USER: gboard
      POSTGRES_PASSWORD: ${DB_PASSWORD}
    volumes:
      - postgres_data:/var/lib/postgresql/data
    restart: unless-stopped
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U gboard"]
      interval: 10s
      timeout: 5s
      retries: 5

  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile.prod
    environment:
      DATABASE_URL: postgresql://gboard:${DB_PASSWORD}@postgres:5432/gboard
      JWT_SECRET: ${JWT_SECRET}
      GIN_MODE: release
      PORT: 8080
    ports:
      - "8080:8080"
    depends_on:
      postgres:
        condition: service_healthy
    restart: unless-stopped

  frontend:
    build:
      context: ./frontend
      dockerfile: Dockerfile.prod
    environment:
      NEXT_PUBLIC_API_URL: ${API_URL}
    ports:
      - "3000:3000"
    depends_on:
      - backend
    restart: unless-stopped

volumes:
  postgres_data:
```

### Environment Variables

Create a `.env` file:

```env
# Database
DB_PASSWORD=your-secure-password-here

# JWT
JWT_SECRET=your-super-secret-jwt-key-change-this

# API
API_URL=https://api.yourdomain.com/graphql

# Domain (for CORS)
DOMAIN=yourdomain.com
```

### Deploy

```bash
# Build and start services
docker-compose -f docker-compose.prod.yml up -d

# View logs
docker-compose logs -f

# Stop services
docker-compose down
```

## VPS Deployment

Deploy to a VPS (DigitalOcean, AWS EC2, etc.)

### 1. Server Setup

```bash
# Update system
sudo apt update && sudo apt upgrade -y

# Install Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# Install Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose

# Install Git
sudo apt install git -y
```

### 2. Clone Repository

```bash
cd /opt
sudo git clone https://github.com/your-repo/gboard.git
cd gboard
```

### 3. Configure

```bash
# Create .env file
sudo nano .env

# Paste your environment variables
# Save and exit (Ctrl+X, Y, Enter)
```

### 4. Deploy

```bash
# Build and start
sudo docker-compose -f docker-compose.prod.yml up -d

# Enable auto-start on reboot
sudo systemctl enable docker
```

### 5. Setup Nginx Reverse Proxy

```bash
# Install Nginx
sudo apt install nginx -y

# Create config
sudo nano /etc/nginx/sites-available/gboard
```

```nginx
# /etc/nginx/sites-available/gboard
server {
    listen 80;
    server_name yourdomain.com;

    # Frontend
    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }

    # Backend API
    location /graphql {
        proxy_pass http://localhost:8080;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

```bash
# Enable site
sudo ln -s /etc/nginx/sites-available/gboard /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
```

### 6. Setup SSL with Let's Encrypt

```bash
# Install Certbot
sudo apt install certbot python3-certbot-nginx -y

# Get certificate
sudo certbot --nginx -d yourdomain.com

# Auto-renewal is configured automatically
```

## Database Backup

### Automatic Backups

```bash
#!/bin/bash
# backup.sh - Run daily via cron

DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR="/backups"
DB_NAME="gboard"

# Create backup
docker-compose exec -T postgres pg_dump -U gboard $DB_NAME | gzip > "$BACKUP_DIR/gboard_$DATE.sql.gz"

# Keep only last 7 days
find $BACKUP_DIR -name "gboard_*.sql.gz" -mtime +7 -delete

# Upload to S3 (optional)
aws s3 cp "$BACKUP_DIR/gboard_$DATE.sql.gz" s3://your-bucket/backups/
```

### Cron Schedule

```bash
# Edit crontab
crontab -e

# Add daily backup at 2 AM
0 2 * * * /path/to/backup.sh
```

### Restore from Backup

```bash
# Stop application
docker-compose down

# Restore database
gunzip -c backup.sql.gz | docker-compose exec -T postgres psql -U gboard gboard

# Start application
docker-compose up -d
```

## Scaling

### Horizontal Scaling

```yaml
# Scale backend instances
docker-compose up -d --scale backend=3

# Add load balancer
  nginx:
    image: nginx:alpine
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf
    ports:
      - "80:80"
    depends_on:
      - backend
```

### Database Scaling

```yaml
# Add read replica
  postgres-replica:
    image: postgres:16-alpine
    environment:
      POSTGRES_DB: gboard
      POSTGRES_USER: gboard
      POSTGRES_PASSWORD: ${DB_PASSWORD}
      POSTGRES_PRIMARY_HOST: postgres
    volumes:
      - postgres_replica_data:/var/lib/postgresql/data
```

## Troubleshooting

### Container Won't Start

```bash
# Check logs
docker-compose logs backend

# Check container status
docker-compose ps

# Restart specific service
docker-compose restart backend
```

### Database Connection Issues

```bash
# Test database connection
docker-compose exec backend ping postgres

# Check database logs
docker-compose logs postgres
```

### High Memory Usage

```bash
# Check resource usage
docker stats

# Limit container resources
services:
  backend:
    deploy:
      resources:
        limits:
          cpus: '0.5'
          memory: 512M
```
