# Frontend Overview

The GBoard frontend is a modern React application built with Next.js 16, TypeScript, and Tailwind CSS.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **UI Library**: React 19
- **Styling**: Tailwind CSS + shadcn/ui
- **Animations**: Framer Motion
- **GraphQL**: Apollo Client
- **Drag & Drop**: @dnd-kit
- **Form Handling**: React Hook Form
- **Testing**: Playwright

## Key Features

### 1. App Router (Next.js 16)

Uses the modern App Router with server and client components:

```tsx
// app/(main)/dashboard/page.tsx
import { ProjectList } from '@/components/projects/ProjectList'

export default function DashboardPage() {
  return (
    <div className="container mx-auto p-6">
      <h1 className="text-3xl font-bold mb-6">Dashboard</h1>
      <ProjectList />
    </div>
  )
}
```

### 2. Apollo Client Integration

GraphQL queries and mutations with Apollo:

```tsx
'use client'

import { useQuery } from '@apollo/client'
import { GET_PROJECTS } from '@/lib/graphql/queries/projects'

export function ProjectList() {
  const { data, loading, error } = useQuery(GET_PROJECTS)
  
  if (loading) return <Skeleton />
  if (error) return <ErrorMessage error={error} />
  
  return (
    <div className="grid grid-cols-3 gap-4">
      {data.projects.map(project => (
        <ProjectCard key={project.id} project={project} />
      ))}
    </div>
  )
}
```

## Running the Frontend

### Development

```bash
# Install dependencies
bun install

# Run dev server
bun run dev

# Open http://localhost:3000
```

### Production Build

```bash
# Build for production
bun run build

# Start production server
bun run start
```

### Testing

```bash
# Run Playwright tests
bun playwright test

# Run in UI mode
bun playwright test --ui

# Run specific test
bun playwright test board.spec.ts
```
