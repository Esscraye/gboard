# Welcome to GBoard Documentation

Welcome to the official documentation for **GBoard** - a modern, open-source project management platform built with cutting-edge technologies.

## What is GBoard?

GBoard is a powerful Jira-inspired project management tool designed for modern development teams. It combines the flexibility of Kanban boards with a blazing-fast tech stack to deliver an exceptional user experience.

### Key Features

- 🚀 **Lightning Fast** - Built with Go and Next.js for optimal performance
- 📊 **Kanban Boards** - Intuitive drag-and-drop interface for task management
- 🔄 **Real-time Collaboration** - See updates instantly across your team
- 🔐 **Secure** - JWT-based authentication and authorization
- 🎨 **Modern UI** - Beautiful, responsive interface with dark mode support
- 📱 **CLI Tool** - Manage projects directly from your terminal
- 🔌 **GraphQL API** - Flexible and efficient data querying

## Technology Stack

### Backend
- **Go** - High-performance backend server
- **GraphQL** - Modern API with gqlgen
- **GORM** - Powerful ORM for database operations
- **PostgreSQL/SQLite** - Flexible database options

### Frontend
- **Next.js 16** - React framework with App Router
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first styling
- **Framer Motion** - Smooth animations
- **Apollo Client** - GraphQL client

### CLI
- **Cobra** - Modern CLI framework
- **Go** - Cross-platform command-line tool

## Why GBoard?

### Open Source & Free
GBoard is completely open source and free to use. No hidden costs, no premium tiers - just a powerful project management tool available to everyone.

### Developer-First
Built by developers for developers, GBoard focuses on the features that matter most to technical teams.

### Modern Architecture
Leveraging the latest technologies ensures GBoard is fast, maintainable, and ready for the future.

### Self-Hosted
Keep full control of your data by hosting GBoard on your own infrastructure.
